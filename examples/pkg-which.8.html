NAME

pkg which - display which package installed a specific file

SYNOPSIS

pkg which -gopqm file pkg which --glob --origin --path-search --quiet --show-match file

DESCRIPTION

pkg which is used for displaying the package that installed file.

OPTIONS

The following options are supported by pkg which:

  • -g, --glob

    Treat file as a glob pattern.

  • -m, --show-match

    Show files that matched the glob pattern (requires --glob).

  • -o, --origin

    Show the origin of the package instead of name-version.

  • -p, --path-search

    Search for the filename in PATH .

  • -q, --quiet

    Be quiet.

ENVIRONMENT

The following environment variables affect the execution of pkg which. See pkg.conf(5) for further description.

  • PKG_DBDIR

  • PATH

FILES

See pkg.conf(5).
